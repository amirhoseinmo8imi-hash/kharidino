# خریدینو — نسخه Pro Commerce

ویژگی‌های این نسخه:
- رابط کاربری Dark / Glassmorphism و انیمیشن‌های حرفه‌ای
- صفحه خانه، امکانات، درباره ما و تماس با ما
- جست‌وجوی محصول و مقایسه قیمت فروشگاه‌ها
- سبد خرید با تغییر تعداد و حذف محصول
- ثبت سفارش برای کاربران واردشده
- صفحه «سفارش‌های من» و نمایش وضعیت سفارش
- پنل مدیریت سفارش‌ها و تغییر وضعیت
- مدیریت محصولات، دسته‌بندی‌ها، فروشگاه‌ها، قیمت‌ها و کاربران
- طراحی Responsive برای موبایل

## اجرا

```bash
pip install -r requirements.txt
python app.py
```
