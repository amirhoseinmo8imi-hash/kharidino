# اپلیکیشن اندروید خریدینو

نسخه اندروید، وب‌سایت خریدینو را همراه خود داخل APK بسته‌بندی می‌کند و نسخه کامل Flask را روی سرور داخلی گوشی اجرا می‌کند؛ برای بازشدن صفحات محلی به دامنه یا هاست عمومی نیاز نیست.

## معماری

- Python 3.11 با Chaquopy داخل APK.
- اجرای ورودی اصلی سایت یعنی `run_kharidino.py`؛ بنابراین ماژول‌های کاتالوگ، امنیت، سفارش، پرداخت، حسابداری، فروشنده، پروفایل و API موبایل نیز ثبت می‌شوند.
- نمایش صفحات اصلی با WebView از آدرس loopback یعنی `127.0.0.1:8765`.
- بسته‌بندی قالب‌ها، CSS، JavaScript، تصاویر و ماژول‌های Python لازم در APK.
- دیتابیس SQLite، secret نشست‌ها و فایل‌های آپلودشده در فضای خصوصی برنامه.
- کپی نسخه جدید کد/قالب‌ها هنگام ارتقای نسخه برنامه، بدون جایگزین‌کردن دیتابیس و آپلودهای قبلی.

## داده‌های شروع

در اولین اجرا، seed رسمی پروژه اجرا می‌شود و تنظیمات پایه، دسته‌بندی‌ها، کاتالوگ اولیه و داده‌های نمایشی موردنیاز را ایجاد می‌کند. قیمت‌های داخل seed نمونه‌اند و قیمت زنده محسوب نمی‌شوند. در نصب مستقل، اولین حسابی که روی همان دستگاه ثبت‌نام کند مدیر محلی می‌شود؛ این رفتار فقط در حالت داخلی اندروید فعال است و روی سایت میزبانی‌شده اثر ندارد. دیتابیس واقعی محیط سایت در مخزن GitHub موجود نیست؛ بنابراین کاربران، سفارش‌ها، تنظیمات و اطلاعات واقعی قبلی از سایت آنلاین به این APK منتقل نشده‌اند.

## آفلاین و آنلاین

صفحات و داده‌های محلی، ثبت‌نام/ورود محلی، سبد و داده‌هایی که به SQLite وابسته‌اند می‌توانند روی همان دستگاه اجرا شوند. پرداخت واقعی، پیامک/ایمیل، بازیابی رمز از راه دور، قیمت زنده، هوش مصنوعی ابری، سرویس‌های بیرونی، ارسال سفارش به فروشنده و همگام‌سازی چنددستگاهی به اینترنت و سرور/ارائه‌دهنده مربوط نیاز دارند. سفارش آفلاین فقط روی دستگاه ثبت می‌شود تا بعداً لایه همگام‌سازی ساخته شود.

## ساخت

در Android Studio پوشه `mobile_app/android` را باز کن. یا با Gradle 8.9 و JDK 17 از همان پوشه اجرا کن:

```powershell
gradle assembleDebug
```

ساخت اولیه به اینترنت برای دریافت Gradle، Android SDK و وابستگی‌های Python نیاز دارد. APK نصب‌شده برای اجرای صفحات داخلی به هاست عمومی نیاز ندارد.

جزئیات در [ANDROID_LOCAL_HOST.md](ANDROID_LOCAL_HOST.md) است.
