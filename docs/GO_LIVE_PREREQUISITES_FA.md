# پیش‌نیازهای تکمیل و انتشار خریددینو

این سند ورودی‌هایی را فهرست می‌کند که از داخل مخزن کد قابل جعل یا حدس‌زدن نیستند. هیچ کلید، رمز، مجوز یا اطلاعات پرداختی را در Git ثبت نکنید؛ مقادیر محرمانه باید از طریق Secret Manager محیط استقرار تحویل شوند.

## ورودی‌های لازم از مالک محصول/عملیات

| حوزه | ورودی لازم | چرا لازم است |
|---|---|---|
| پرداخت ایران | حساب پذیرندگی فعال، کلید API و قرارداد رسمی PSP، URL عمومی HTTPS و دسترسی به محیط تست | آزمون واقعی پرداخت، callback، verify، refund و تطبیق مالی |
| واحد پول | تأیید کتبی اینکه داده‌های فعلی هر ستون قیمت/سفارش به ریال است یا تومان؛ نمونه داده ناشناس | جلوگیری از تبدیل اشتباه و آسیب به سوابق مالی |
| سینمای آنلاین | قرارداد/مجوز نمایش هر عنوان، قلمرو، تاریخ شروع/پایان، محدودیت دستگاه و حق پخش | انتشار محتوا بدون مجوز قابل قبول نیست |
| بلیت سینما | قرارداد یا API تأمین‌کننده/سینما، شناسه سالن‌ها، نقشه صندلی، سانس و قواعد لغو/استرداد | جلوگیری از نمایش ظرفیت و صندلی غیرواقعی یا فروش تکراری |
| رسانه | فضای Object Storage، دامنه CDN، سیاست retention، سقف حجم/مدت و سرویس پردازش/transcode | فایل محلی وب‌سرور راهکار Production برای رسانه نیست |
| اپ اندروید | دامنه Production HTTPS، حساب انتشار Play Console، کلید امضای Release و سیاست حریم خصوصی/مجوزها | ساخت، امضا، انتشار و آزمون واقعی اپ |
| چندکشوری | کشورهای مقصد، ارز پایه/ارز تسویه، PSPها، مالیات، حمل‌ونقل، قوانین مصرف‌کننده و سیاست داده هر کشور | پیاده‌سازی درست چندارزی و چندقلمرویی |

## معیار خروج مشترک برای هر مرحله

1. Migration قابل بازگشت و آزموده‌شده؛ بدون تغییر مخرب داده موجود.
2. تست واحد، یکپارچه، امنیتی و انتها‌به‌انتها برای مسیرهای موفق و شکست.
3. کنترل دسترسی سمت سرور و ثبت audit برای عملیات حساس.
4. مانیتورینگ، لاگ بدون اطلاعات محرمانه، backup و روش rollback.
5. اجرای staging با سرویس/داده آزمایشی و تأیید مالک محصول قبل از Production.
6. هیچ مرحله‌ای صرفاً به‌دلیل وجود UI یا route «تکمیل» محسوب نمی‌شود.

## ترتیب اجرا

مطابق ROADMAP.md: ۱) هسته مالی و سفارش، ۲) بازارگاه و مقایسه قیمت، ۳) Explore و رسانه، ۴) سینمای آنلاین، ۵) رزرو و QR، ۶) Android Native و WebView، ۷) چندکشوری/چندارزی.

## وضعیت فعلی شاخه

- Explore MVP پیاده‌سازی شده و در PR شماره ۲۷ منتظر بازبینی/ادغام است؛ ذخیره‌سازی ابری، پردازش ویدئو، CDN و پخش تطبیقی هنوز باقی است.
- هسته تجارت/پرداخت و marketplace دارای پیاده‌سازی‌های موجودند، اما اتصال Production و ممیزی واحد پول نیازمند ورودی مالک و آزمون محیط واقعی است.
- پایه Android Compose و API فقط‌خواندنی وجود دارد؛ محصول موبایل کامل نیست.
- سینما، رزرو صندلی و چندکشوری/چندارزی در این شاخه هنوز تحویل نشده‌اند.
