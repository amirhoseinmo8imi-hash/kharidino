# خریدینو — Ultimate Release

این شاخه لایه حرفه‌ای فروشگاه و پنل مدیریت را روی ساختار موجود پروژه اضافه می‌کند.

## اجرا

```powershell
python run_kharidino.py
```

سپس:

- `http://127.0.0.1:5000`
- پنل مدیریت از لینک «مدیریت سایت» برای مدیر قابل دسترسی است.

## ویژگی‌های این مرحله

- fallback خودکار تصویر محصولات بدون تصویر اصلی
- صفحه محصول غنی با معرفی، مشخصات، نظر و فروشگاه‌ها
- جستجوی سریع در بخش‌های پنل مدیریت
- ظاهر یکپارچه‌تر کارت‌ها، جدول‌ها و پنل
- CSRF و same-origin برای درخواست‌های تغییر‌دهنده
- محدودیت اندازه درخواست و اعتبارسنجی محتوای آپلود
- جلوگیری از ثبت تکراری checkout با ledger دیتابیسی
- عدم نمایش مشخصات ساختگی برای محصول

قبل از merge شدن، Quality Gate پروژه و CI باید سبز باشند.
