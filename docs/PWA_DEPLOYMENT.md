# خریدینو PWA — راهنمای استقرار و تست

## قابلیت‌ها
- نصب از مرورگرهای پشتیبانی‌شده روی HTTPS (یا localhost).
- کش محدود به فایل‌های استاتیک عمومی و صفحه آفلاین؛ صفحات حساب، سفارش، پرداخت، مدیریت، API و پیام‌ها cache نمی‌شوند.
- پیش‌نویس مقدار سبد خرید و علاقه‌مندی‌ها فقط روی همان دستگاه/مرورگر ذخیره می‌شوند و همگام‌سازی حساب نیستند.
- سفارش و پرداخت آفلاین انجام نمی‌شوند. پس از اتصال، کاربر باید سبد را بررسی و با سرور ثبت کند.

## چک‌لیست قبل از انتشار
1. محیط production را با HTTPS و SECRET_KEY پایدار تنظیم کنید.
2. مرورگر DevTools > Application > Manifest را بررسی کنید؛ آیکون‌ها و start_url باید سالم باشند.
3. Service Worker را بررسی کنید و Cache Storage فقط فایل‌های عمومی را شامل شود.
4. روی Android Chrome نصب، بازشدن standalone، به‌روزرسانی worker و offline navigation را بررسی کنید.
5. در حالت offline تلاش برای checkout را بررسی کنید؛ هیچ درخواست سفارش/پرداختی نباید در صف یا cache قرار بگیرد.
6. پس از reconnect، سبد را دستی بازبینی و به‌صورت online ارسال کنید.
7. روی iOS Safari، نصب از Share > Add to Home Screen را جداگانه بررسی کنید؛ beforeinstallprompt در آن پشتیبانی نمی‌شود.
8. در صورت بروز مشکل، داده‌های سایت/Service Worker را پاک کنید و دوباره تست کنید.

## محدودیت
PWA به‌تنهایی APK بومی، push notification، sync حساب یا پخش آفلاین ویدئو ایجاد نمی‌کند. این موارد نیازمند زیرساخت و تست جداگانه هستند.


## اجرای محلی روی Windows (آماده‌سازی اولیه)
1. Python 3.11 یا جدیدتر را نصب کنید و گزینه Add Python to PATH را فعال کنید.
2. فایل `setup_windows.bat` را اجرا کنید و منتظر نصب وابستگی‌ها بمانید.
3. پس از پایان نصب، `start_windows.bat` را اجرا کنید.
4. مرورگر را روی `http://127.0.0.1:5000` باز کنید. (برنامه فعلاً ممکن است روی رابط‌های شبکه نیز گوش دهد؛ برای استفاده عمومی/اینترنتی مناسب نیست.)
5. این راه‌انداز محلی، نصب‌کننده Windows (MSI/EXE)، APK یا استقرار Production نیست؛ اعتبارسنجی روی دستگاه واقعی و تست کامل هنوز لازم است.
