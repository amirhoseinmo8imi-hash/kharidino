# حسابداری حرفه‌ای خریدینو

## مسیرها

- `/admin/accounting` — دفتر مالی مدیر/مالک
- `/seller/accounting` — دفتر مالی اختصاصی هر فروشنده

## امکانات

- فروش ناخالص و خالص
- کمیسیون پلتفرم
- هزینه‌های عملیاتی و سود عملیاتی
- مانده قابل تسویه فروشنده
- درخواست تسویه و ثبت پرداخت توسط مدیر
- دفتر فروش و وضعیت تراکنش‌ها
- فیلتر بازه زمانی
- خروجی CSV برای گزارش مالی
- تفکیک کامل فروشنده با `store_id` سمت سرور؛ هیچ شناسه فروشنده از ورودی کاربر برای دسترسی مالی پذیرفته نمی‌شود
- تمام عملیات تغییر وضعیت زیر CSRF و کنترل نقش موجود پروژه اجرا می‌شوند

## منبع داده

فروش‌ها از `SellerLedger` موجود در سیستم marketplace خوانده می‌شوند تا یک سفارش در چند سیستم مالی تکرار و دوباره محاسبه نشود. رکوردهای جدید فقط برای هزینه‌های پلتفرم و درخواست‌های تسویه نگهداری می‌شوند.
